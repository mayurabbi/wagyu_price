# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

* リモートリポジトリ：ネット上に配置して複数人で共有するためのリポジトリ。
* ローカルリポジトリ：開発者一人が一人で使用するために自分のPC上に配置したリポジトリ。

## プッシュとマージの違いは何でしょうか？

* pushはローカルブランチの変更履歴をリモートにアップすることをいう。
* mergeは別のブランチの変更履歴を該当のブランチに反映させることをいう。

## コミットとプッシュの違い

* commitはデータをセーブすることでpushはcommitされたファイルをリモートにアップすること。

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

* そのファイルでどのような変更を加えたのか簡潔に誰が見てもわかるように記述するのが最適。

## プレフィックスとは
* 追加→メッセージの先頭につけ、一目で変更内容を理解しやすくするラベルのこと。
* 追加→git commit -m 'docs: README.mdに追加質問を回答'

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

* ローカルでマージするフローはローカルブランチに指定したブランチの変更履歴を取り込んだだけなのでWeb上では反映されてない状態。
* プルリクエストでマージするフローはローカルブランチをリモートブランチにpushし変更内容の確認依頼ができるためコードレビューを行ってからマージすることができる。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

1. 先にマージした内容を取り込む
1. 後にマージしようとしている変更内容を取り込む
1. どちらの変更内容も取り込む
1. 不明点あれば必ず相談する。
